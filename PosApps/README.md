# POS Apps

`PosApps` contains compact point-of-sale and kiosk presentation intended for dedicated in-world terminals.

POS UI must submit only identifiers and player choices. Product validation, stock, payment, fulfillment, and receipts remain server-authoritative in resources such as `m-business`, `m-banking`, `m-inventory`, and `m-documents`.

Current module: [Kiosk](Kiosk/README.md).
